**Data Analytics & Machine Learning Project**

The objective of this project is to perform end‑to‑end data analysis using Python, derive meaningful insights through Exploratory Data Analysis (EDA), visualize trends using Power BI–style dashboards, and build machine learning models to make predictions that support data‑driven decision‑making.
